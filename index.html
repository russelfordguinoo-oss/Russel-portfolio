My journey started with Computer Engineering, where I learned how hardware, software, and systems come together. Over time, my interest moved deeper into software development, databases, and the technologies behind modern applications.

That mindset led me to start building my own projects. I've worked with JavaScript, React, Node.js, Express, SQL, and MySQL, creating applications that solve practical problems rather than just demonstrating code.

Now, I'm expanding into cloud computing, AI, machine learning, and modern software engineering, with the goal of becoming a Cloud Software Engineer capable of building reliable and intelligent systems.
